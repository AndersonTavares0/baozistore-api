# Como contribuir

Este é um projeto acadêmico individual da disciplina Desenvolvimento Web Back-End (UNINTER). Sugestões podem ser registradas em uma issue; alterações devem explicar o problema, seguir o estilo Java existente e incluir testes quando mudarem comportamento.

## Preparar e verificar

Use JDK 21 e execute:

```bash
./mvnw test
```

Para iniciar a API: `./mvnw spring-boot:run`.

## Commits

Use Conventional Commits, por exemplo `feat: valida quantidade do pedido` ou `docs: atualiza exemplos da API`. Não inclua credenciais, arquivos `target/` ou dados pessoais além dos já publicados pelo autor no projeto.
